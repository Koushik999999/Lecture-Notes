Clustering Algorithms


--> K-Means Algorithm

	--> Randomly Decide the number of groups
	
	--> Randomly divide them into the groups based on certain points

	--> Calculate the centroid of each group 

	-->  divide the groups into two; i.e calculate the Euclidean distance of each point from the centroids and assign them to the group with the shortest distance.
	
	--> Recalculate the centroids and repeat the process

	--> centroids stop updating/starts becoming stable after a certain number of iterations, the final version of clustering will be our answer 



--> WCSS (Within Cluster sum of squares)

	--> This will help us decide number of clusters
	

--> BCSS (Between Cluster Sum of squares)

	--> make sure the clusters are as far as possible

	--> Single Linkage (get the nearest points)

	--> dist. between centroids

	--> dist. between farthest points

	--> These are called hyperparameters
 
--> TSS(total sum of squares) = WCSS + BCSS


--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------



--> Hierarchical clustering


	--> works with smaller amount of data

	--> Assumes every single point is a cluster

	--> Calculates distance between every two points

	--> combine the points with the smallest distance

	--> repeat the process
