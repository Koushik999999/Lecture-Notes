Linear Regression

--> Find the best fit line

--> RMSE = (MSE)^0.5

	--> Intuition (eg. RSME is 50
			
			predicted value is +- 50 away from actual value

--> median absolute and median errors are also sometimes considered



--> R^2 --> co-efficient of determination

	--> The closer it is to one, the better our model is 

	 --> How better your model is better than the most basic model(i.e giving mean as the output for every prediction)

	--> R^2  = 1 - (MSE of your model)/(MSE of average model(model every input gives the average of all values as the output))



--> We need a linear data sent and each row/data point should be independent of each other for linear regression to work

--> error distribution should be normal

--> multi collinearity should not happen
