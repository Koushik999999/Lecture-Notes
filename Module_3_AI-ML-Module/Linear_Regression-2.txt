Linear Regression - 2


--> VIF method

	--> treat one of the feature as dependant variable and calculate R^2 ,

	--> If R^2 is high then there is a multicollinearity

	--> VIF = 1/(1- R^2)


	--> If VIF > 10, drop the value/feature/coloumn --> thumb rule 


--> Bias and Variance

--> to avoid over fitting

--> Lasso Regression/ L1 regression --> balancing the loss function by adding the sum of squares of weights 

--> L2 Regression --> sum of absolute values of weights 

--> multiply the sum with Lambda to control it
